Checking acceleration…

First use downloads the runtime plus a model: Standard about 5 MB; Detailed about 67 MB. Standard runs a native 4× model; its 2× output is downsampled per tile. Model caching and session reuse avoid repeat work where possible. Output previews are capped at 1200 px. The full output is preserved for download.

Requires float32 RGB [0,1], dynamic NCHW dimensions and matching native scale. External model URLs must permit browser CORS. Leave empty for the supplied model.
